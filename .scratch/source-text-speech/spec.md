# Source Text 朗读

## 已确认需求

- 使用 macOS 本地文本转语音，不依赖翻译服务或第三方 API。
- 手动朗读固定的 Source Text，支持单词、句子和段落。
- 自动识别中英文；中英混合按主要语言朗读；其他语言提示暂不支持。
- 英文默认美式，设置中可切换英式。
- 翻译结果页和完整原文页共享朗读状态，都提供朗读／停止动作。
- 使用 Command+Shift+P 切换朗读／停止。
- 两个页面之间切换继续播放，退出 Translation Session 停止。
- 新朗读替换旧朗读，不排队。
- 使用默认语速，不提供暂停、续播或语速设置。
- 缺失对应语音时提示安装系统语音，不自动换口音。
- 启动或播放失败时显示错误并允许重试。

## 已确认的验证边界

- 语言与音色选择：中英文、混合文本、不支持的语言、美式／英式偏好。
- 朗读生命周期：开始、停止、替换、结束、错误后重试和会话退出清理。
- 两页共享动作与播放状态：切页不中断，快捷键切换朗读／停止。

## 审查与交付

- 实测发现 macOS 将 apple、cat、dog 等孤立英文词识别为其他语言。单个拉丁字母词且识别置信度低于 0.9 时按英文处理；高置信度非英语仍拒绝。通过真实 macOS 识别回归测试覆盖该限制。
